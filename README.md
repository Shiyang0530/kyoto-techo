# kyoto-techo

## 共享资料库（规范 v2.0）

本书数据已迁入京都、瑞士共用的资料库（暂存在 Swiss-Tour 仓库的 `src/techo/`）。`index.html` 里的数据部分由 `techo/tools/build_kyoto.py` 从资料库生成，请改资料库，不要直接改 `index.html` 的数据。每个条目有 7 位编号（如 1000001 金阁寺），`img/` 里的图片文件名改为「编号_用途」（`_cover`、`_cover_sakura` / `_autumn` / `_snow`、`_map`、`_02`…）。网址和本地保存的收藏、标签、行程仍沿用旧键，不受影响。
